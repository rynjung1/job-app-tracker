Privacy Policy — Job Application Tracker

Last updated: 2026-09-15

Job Application Tracker is a browser extension that automatically logs job applications you submit on supported job sites (currently LinkedIn, Greenhouse, Lever and Ashby) to a Google Sheet you own. This page explains what data the extension accesses, stores, and sends, in plain terms.

What the extension reads from job pages

When you click Easy Apply or Submit on a supported job posting page, the extension reads the job title, company name, location, and page URL directly from that page. On LinkedIn and Ashby its code is loaded on every page of those sites, because they move between pages without reloading them, but it acts only on job pages — addresses under linkedin.com/jobs/, and Ashby's application pages — and ignores the rest. On Lever it is loaded only on application form pages. It does not read your profile, account information, messages, or any other page content on those sites.

Where your data goes

When you apply, those four fields — plus the date, your resume version, blank Status/Notes fields for you to fill in, and a random ID in a hidden column that's used only to avoid saving the same application twice — are written as a new row to a spreadsheet you control. On LinkedIn this happens when you click Easy Apply. On Greenhouse it happens once Greenhouse confirms your application was submitted, so an attempt the form rejects isn't logged. On Lever it happens when the application form is submitted, after the form's own checks pass. On Ashby it happens when you click Submit Application.

The extension can only access files it creates itself (Google's drive.file permission) — it cannot see or modify any other file in your Google Drive. When you connect, it creates that spreadsheet and formats it. When you open the extension's popup, it reads the Company, Title and Status of your recent rows back from that same spreadsheet, so it can show each application's current status, and before you change an application's status or resume version from the popup, it reads that row to check it still matches. It also reads the spreadsheet's header row, to find its columns; when it retries saving an application, the hidden ID column, so it doesn't save the same application twice; and if you've renamed the sheet's tab, the spreadsheet's tab names, to find it again. It also asks Google Drive whether that spreadsheet is in the trash (only that one file's trash status, never its contents), after each application it logs, when you open the popup, and every 5 minutes while applications are waiting to be saved or the sheet has already been found in the trash or deleted, so it stops writing to a sheet you've thrown away. It reads nothing else from your Drive.

Job Application Tracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

The extension has no server of its own. Data goes directly from your browser to Google's servers, using Google's official APIs, over HTTPS. Nothing passes through, or is stored on, any server operated by this extension's developer.

What's stored on your device

The extension stores the following locally, in your browser's extension storage (not synced to any account or accessible to other extensions or websites):

  • A short-term queue of job applications waiting to be written, in case of a network or sign-in issue.
  • Briefly, for a Greenhouse application: the job title, company, location and page URL from your Submit click, kept in session storage (memory only) until Greenhouse confirms the submission. It's deleted when that application is logged or when you close the browser. After 30 minutes it's no longer used, and it's removed the next time you click Submit on a Greenhouse application or open a Greenhouse confirmation page.
  • Your 20 most recent logged applications, so the extension can show you a list where you can change an application's status or resume version at any time (each change updates that one cell in your spreadsheet).
  • Which spreadsheet you've connected.
  • The last resume version you used for each type of role, so future applications can suggest it automatically.
  • If the extension can't reach your spreadsheet because your Google sign-in has lapsed or been removed: when that happened and the error message from Chrome or Google, so it can show a "Sign-in needed" notice until you reconnect. It's deleted as soon as the extension reaches your spreadsheet again.
  • If your spreadsheet is moved to Google Drive's trash or deleted: which of the two, when that was noticed, and Google's error message, so the extension can hold new applications and tell you. It's deleted as soon as the sheet can be used again or you create a new one.
  • While the extension's Settings window is open, that window's number, in session storage (memory only), so opening Settings again brings the same window forward.

The extension doesn't store any sign-in credential: Chrome itself keeps the Google access token it uses. None of this is ever transmitted anywhere except as described above.

What this extension does not do

It does not use analytics or tracking of any kind. It does not share, sell, or transmit your data to any third party. It does not display ads. It does not access any website other than the specific job sites and the Google APIs described here.

Your control over your data

You can disconnect the extension's access to your Google account at any time from your Google Account's security settings. Uninstalling the extension removes all data stored locally by it. The spreadsheet it created remains yours — deleting it is entirely up to you, the same as any other file in your account.

Changes to this policy

If this policy changes, the "Last updated" date above will change accordingly.
